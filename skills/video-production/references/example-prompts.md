# Example prompts

The [Applied AI guide](https://www.its-applied-ai.com/r/styles) contains 41 examples. Each entry below links to the corresponding original and provides an independently worded prompt you can adapt. Repository recommendations for recreation examples are suggestions for implementation. Use the [repository catalog](repositories.md) for code paths and setup choices.

For examples 32–41, use a five-second 1080×1920 HyperFrames composition when following the guide's production format. Drive motion from its timeline, keep text away from the crop and overlays, and inspect early, middle, and final frames.

## 01 Isometric explainer

**Start with** Lemo-Opuscar. [Original example 1](https://www.its-applied-ai.com/r/styles#:~:text=1.%20Isometric%20explainer%20prompt).

> Use the isometric infographic style to follow a message from a phone through a radio tower and fibre connection to a data centre, then show the reply. Keep all four stations in view and activate their labels as the signal arrives. Use a seven-second 1920×1080 timeline. Deliver editable source and an MP4 after checking the route and labels.

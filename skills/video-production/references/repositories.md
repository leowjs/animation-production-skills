# Repository catalog

This catalog covers the ten GitHub repositories linked by the [Applied AI animation guide](https://www.its-applied-ai.com/r/styles). The original titles and example mappings are in the [prompt catalog](example-prompts.md). Repository revisions, star counts, and top-level license labels were checked on 7 November 2026. Review the specific file or asset terms before reuse.

A must entry leads its matching workflow. Optional and supporting entries solve narrower problems. A creative reference can guide a treatment even if the production uses a different renderer.

## Lemo-Opuscar

**Role** — must for isometric.

A code-film style library with detailed treatments and demos. Start here when a fixed isometric viewpoint, route, and timed labels need to tell the story. Also useful for layered paper, ink wash, and retro terminal treatments. Adapt the visual rules to original content. The upstream renderer and plugin are optional.

[Repository](https://github.com/lemomo-ai/lemo-opuscar) · 13,278 stars · MIT.

## Three.js

**Role** — must for web 3D data charts.

A JavaScript 3D library. Its scene graph, meshes, cameras, lighting, and materials give precise control over the visual encoding of a chart. Also useful for product rotations, loops, and flythroughs. Use an existing compatible version and a separate capture path for MP4.

[Repository](https://github.com/mrdoob/three.js) · 117,795 stars · MIT.

At the [reviewed revision](https://github.com/mrdoob/three.js/commit/f2b6a71bdd088d9da387fcc62802323341099b92), start with [examples](https://github.com/mrdoob/three.js/tree/f2b6a71bdd088d9da387fcc62802323341099b92/examples), [src](https://github.com/mrdoob/three.js/tree/f2b6a71bdd088d9da387fcc62802323341099b92/src), [docs](https://github.com/mrdoob/three.js/tree/f2b6a71bdd088d9da387fcc62802323341099b92/docs).

## Blender MCP

**Role** — must for Blender 3D explainers.

A community bridge for controlling Blender from an MCP-capable agent. Prefer it for an editable scene, an exploded assembly, a spatial explanation, or a studio camera. Check the Blender add-on, MCP server, client configuration, and connection before relying on it. The guide's original [blender-mcp URL](https://github.com/ahujasid/blender-mcp) redirects to this repository.

[Repository](https://github.com/ahujasid/mcp-for-blender) · 33,529 stars · MIT.

## Opus video prompt packs

**Role** — must for maths and line art, reference exception.

A collection of prompt and case references. Prefer it for sequencing a proof, labelling a diagram, or finding examples of code-rendered explanations. It supplies ideas, not a runtime. The 969-star repo is the explicitly requested exception to the 1,000-star preference. GitHub lists no repository license and the README attributes the collected work to its original authors. Link to examples and write original adaptations.

## ClaudeAnimationBase

**Role** — optional for hand-painted character animation.

A Claude-oriented starter for expressive cartoon performance. Its animation guide and character implementation help when a presenter needs readable poses and reactions. Check the p5.js setup and asset terms. The production skill can adapt the visual approach in either client.

## React Three Rapier

**Role** — optional for dominoes and physical motion.

React bindings for Rapier physics in React Three Fiber. Prefer it for collisions, rigid bodies, falling dominoes, and Galton boards when the project already uses that stack. Check package compatibility and use fixed-step simulation for capture.

[Repository](https://github.com/pmndrs/react-three-rapier) · 1,535 stars · MIT.

## awesome-opus5-5-videos

**Role** — must as a Glass Mosaic creative reference.

A gallery of prompt and video examples with remakes. Its strength is comparing how phrasing about materials, lighting, and motion translates into visual results. Use example 10 in the Applied AI guide as the actual mosaic brief. The repository is a creative reference, with original media and prompts subject to their own terms.

## pixelfx

**Role** — must for pixel explainers.

A gallery and library of small coded pixel effects with a Claude Code skill. Prefer it when rain, fire, lightning, or similar effects should support distinct educational beats. Inspect the smallest suitable effect and match its resolution and palette to the scene.

## HyperFrames

**Role** — renderer for the paper-plane examples and optional HTML export.

A renderer for deterministic HTML-to-video workflows. Prefer it when an HTML/CSS scene can be made seekable and needs reproducible MP4 output. Inspect the CLI, engine, and its requirements. For clickable stories, use a browser interaction layer for the choices.

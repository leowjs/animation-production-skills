# Stylized Motion Explainers

Read the [repository catalog](../video-production/references/repositories.md), the matching [example prompt](../video-production/references/example-prompts.md), and the relevant [production checks](../video-production/references/production-checks.md).

| Requested style | Start here |
| --- | --- |
| Isometric process | **Lemo-Opuscar**. Read its isometric style guide for a consistent camera angle, staged labels, and a route the viewer can follow. Start from example 01. |
| Glass mosaic | **awesome-opus5-5-videos**. Study how gallery prompts and remakes communicate material, lighting, and transformation. Use the guide's example 10 for the actual mosaic brief and create original geometry. |
| Pixel explainer | **pixelfx**. Select a small effect for each teaching beat and keep sprites, backgrounds, and effects on the same pixel grid. Start from example 11. |
| Paper-cut, retro terminal, or ink wash | **Lemo-Opuscar**. Read the specific style file and adapt its visual rules to the new subject. |
| Hand-painted character performance | **ClaudeAnimationBase** is optional. Check its starter and pose examples when a presenter needs to act or react. Use original characters where the project calls for them. |

For a film, give each beat a visible change and a readable hold. Preview the hardest transition and a frame with the longest label. HyperFrames is a renderer option for seekable HTML scenes and the guide's paper-plane examples. Choose it based on the project's runtime and export needs.

For a clickable story, map choices and outcomes first. Use a small, self-contained browser project when practical. Keep choice controls separate from the artwork and provide a replay path. Test each branch, touch controls, keyboard focus, and a narrow mobile viewport. When the output is video, put questions and pause cues in the timeline so an adult can guide the interaction.

# Blender 3D Explainers

Read the [repository catalog](../video-production/references/repositories.md), the matching [example prompt](../video-production/references/example-prompts.md), and the relevant [production checks](../video-production/references/production-checks.md).

**Blender MCP is the first resource for a Blender 3D explainer.** Verify that the client can connect to the intended Blender instance. Confirm the target scene before editing. If a connection is unavailable, check whether the user can run a supplied Blender Python script or review a storyboard while setup is pending.

Block out the camera and simplified objects before detailed materials. For an exploded view, keep parts identifiable in both assembled and separated states. Verify naming, placement, and the sequence of motion against the supplied diagram or product evidence. For spatial data, keep units and geometry proportional and use a final comparison view.

Preview stills or a short viewport render. For production, use approved assets and an available render configuration. Save the editable Blender scene or reproducible source script and check any rendered output requested.
